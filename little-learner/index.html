Little Sreeo Support

iPhone and iPad · iOS 16 or later · Education · Ages 4–8

This page is for questions about Little Sreeo. There is no account. Letters, numbers, writing, math, XP, and badges stay on this device. Version 1.0 has no ads.

Getting started

  • On first launch, type the child’s name and choose girl or boy. Home then says Good morning, Name! with that look.
  • On Home, tap Start on Today’s Mission.
  • Each letter follows the same path: Learn → Trace → Write → Find → stars → World Map → next letter.
  • Use Learn for Alphabet, Numbers, Writing, Math, and Times Tables.
  • Play has five short games. Rewards shows XP, badges, and the world map.

Parent area

Parent is behind a PIN. The default PIN is 1234. There you can see learning time, change the child’s name and look, turn sound on or off, lock the parent area, reset progress, or open our other apps in the App Store.

Voice

Listen and lesson prompts use the iPhone or iPad’s built-in speech. Turn the device volume up. Sound can be toggled in Parent.

Reset

Reset child progress in Parent, or delete the app, to remove XP and lessons from this device. There is no cloud backup.

Privacy

Progress stays on this device. See the Privacy Policy.
